# Home files in a private directory

fmx binds its Home sockets and lock inside `/tmp/fmx-<uid>`, created 0700 and refused when it is not ours or is open to others, rather than at names of its own directly in a world-writable `/tmp`: a Runtime's exit unlinks its socket, and the Fx processes the Companion keeps holding would report to whoever took the freed name — session titles summarize prompt text. Moving them blacks out lifecycle for Agents that survive the upgrade, because those were handed the old path at launch; they keep running and the next Runtime adopts them.
